# Legal Documentation

This directory contains the legal documentation for the Car Price Prediction AI application.

## 📋 Documents Included

### 1. Terms and Conditions (`TERMS_AND_CONDITIONS.md`)
- **Purpose**: Legal terms governing the use of the service
- **Key Points**:
  - Service description and limitations
  - User responsibilities and prohibited activities
  - Price prediction disclaimers and accuracy statements
  - Liability limitations and intellectual property rights
  - Data usage and privacy commitments
  - Governing law (Indian law)

### 2. Privacy Policy (`PRIVACY_POLICY.md`)
- **Purpose**: Data collection, usage, and protection practices
- **Key Points**:
  - No personal information collection
  - Vehicle data only for price predictions
  - Data security and retention policies
  - User rights and data control
  - Third-party service disclaimers
  - Cookie usage and tracking policies

### 3. Web Pages
- **`public/terms-and-conditions.html`**: User-friendly HTML version of Terms
- **`public/privacy-policy.html`**: User-friendly HTML version of Privacy Policy

### 4. React Components
- **`src/components/LegalDisclaimer.tsx`**: In-app legal disclaimers and notices
- **`LegalDisclaimer`**: Main disclaimer component with warnings and notices
- **`LegalFooter`**: Footer component with legal links and disclaimers
